# ربات فروش استارز، پریمیوم و گیفت تلگرام

ربات فروش خودکار با پنل مدیریت داخل ربات و پنل تحت وب.

## نصب (روی سرور لینوکسی با root)
```bash
bash <(curl -Ls https://raw.githubusercontent.com/rezameisi10-a11y/stars-and-premium-shop/main/starshop.sh)
```
منوی فارسی باز می‌شود؛ گزینه‌ی **۱** را بزنید و توکن ربات، آیدی ادمین و دامنه (اختیاری) را وارد کنید.
بعد از نصب فقط `starshop` را بزنید: آپدیت، بکاپ، تغییر نسخه (گزینه‌ی ۱۷)، لاگ و ... .

## نیازمندی
سرور VPS با Ubuntu 22.04+ یا Debian 12+ و دسترسی به api.telegram.org. دامنه اختیاری است.

توضیح کامل: [README_full.md](README_full.md)

## مینی‌اپ تلگرام
بعد از نصب با دامنه‌ی HTTPS، در ربات دکمه‌ی «🛍 فروشگاه» مینی‌اپ را باز می‌کند: خرید استارز/پریمیوم/گیفت، کد تخفیف، پرداخت، کیف پول، سفارش‌ها و زیرمجموعه‌ها. ادمین‌ها با دکمه‌ی «🛠 پنل مدیریت» بدون رمز وارد پنل کامل می‌شوند.


- عضویت اجباری چندکاناله (نام/رنگ دکمه) و تم روشن/تیره در پنل وب و مینی‌اپ.
