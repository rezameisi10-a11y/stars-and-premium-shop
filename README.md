# ربات فروش استارز، پریمیوم و گیفت تلگرام

ربات فروش خودکار با **پنل مدیریت داخل ربات** و **پنل تحت وب**، دکمه‌های **رنگی** (آبی/سبز/قرمز) با قابلیت تنظیم رنگ و چیدمان از پنل.

## ⚡ نصب با یک دستور (روی سرور لینوکسی، با root)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/rezameisi10-a11y/stars-and-premium-shop/main/starshop.sh) v1.2.0
```
منوی فارسی باز می‌شود؛ گزینه **۱** را بزنید. اسکریپت توکن ربات، آیدی مدیر، دامنه (اختیاری)، رمز پنل وب و ... را می‌پرسد و خودش همه چیز (Python، وابستگی‌ها، سرویس systemd، Caddy با SSL خودکار، فایروال) را نصب می‌کند. بعدش فقط `starshop` را بزنید تا منوی مدیریت (آپدیت، بکاپ، بازگردانی، تغییر توکن/دامنه/پورت، لاگ، عیب‌یابی، حذف و ...) باز شود.

نصب غیرتعاملی:
```bash
BOT_TOKEN=123:ABC ADMIN_IDS=111,222 DOMAIN=panel.example.com NONINTERACTIVE=1 starshop install
```

### گذاشتن پروژه روی گیت‌هاب
همه‌ی فایل‌های این پوشه را در ریشه‌ی مخزن (شاخه‌ی `main`) آپلود کنید؛ مخزن باید public باشد. برای انتشار نسخه‌ی جدید `VERSION` را بالا ببرید، آپلود کنید و یک Release با همان شماره (مثل `v1.2.0`) بسازید. ادمین با گزینه‌ی «آپدیت» یا «تغییر نسخه» (۱۷) نسخه را می‌گیرد.

### نیازمندی‌ها
- سرور لینوکسی (VPS) با دسترسی root؛ Ubuntu 22.04+ یا Debian 12+ توصیه می‌شود. هاست اشتراکی/cPanel کار نمی‌کند.
- سرور باید به تلگرام (api.telegram.org) دسترسی داشته باشد؛ سرور داخل ایران معمولاً ندارد.
- دامنه **اختیاری** است. بدون دامنه ربات کامل کار می‌کند و پنل روی `http://IP:8080` است (بدون HTTPS). برای HTTPS و درگاه زرین‌پال دامنه لازم است: رکورد A دامنه را به IP سرور بزنید و پورت‌های ۸۰ و ۴۴۳ باز باشد.

## امکانات

**فروشگاه (سمت کاربر)**
- خرید Telegram Stars، اشتراک Premium (۳/۶/۱۲ ماهه) و گیفت‌های تلگرام (لیست زنده از خود تلگرام)
- کیف پول، شارژ، تاریخچه تراکنش، سفارش‌های من
- کد تخفیف روی سفارش (درصدی/مبلغ ثابت، محدودیت تعداد/کاربر/حداقل سفارش/اولین خرید/کاربران خاص، ساخت گروهی با پیشوند)
- زیرمجموعه‌گیری با پورسانت و جایزه‌ی عضویت خودکار، با **ضدتقلب**: در صورت فعال بودن عضویت اجباری، پورسانت تا تأیید عضویت واقعی در کانال «در انتظار» می‌ماند، مدت نگهداری قبل از واریز قابل تنظیم است و عضویت دوباره بررسی می‌شود؛ اگر زیرمجموعه کانال را ترک کند جایزه باطل می‌شود
- **چندزبانه**: کاربر زبان ربات را از منو انتخاب می‌کند (ده زبان آماده + هر زبان دلخواه که ادمین اضافه کند)
- قوانین، پشتیبانی، عضویت اجباری در کانال، حالت تعمیر، مسدودسازی کاربر
- ایموجی پریمیوم روی دکمه‌ها (اگر مالک ربات تلگرام پریمیوم داشته باشد)

**پرداخت**: کیف پول · کارت‌به‌کارت با تأیید ادمین (رسید) · درگاه زرین‌پال (تأیید خودکار) · TON و USDT-TRC20 (تأیید خودکار از شبکه)

**تحویل**
- پریمیوم و گیفت: **کاملاً خودکار** با Bot API (از موجودی ستاره ربات)، یا از طریق API یک سرویس‌دهنده‌ی دلخواه، یا با **Marketapp** (خرید خودکار از Fragment، پایین‌تر توضیح داده شده)
- اگر موجودی ستاره ربات کم باشد: سفارش در صف می‌ماند، به ادمین هشدار می‌رسد و پس از شارژ ربات (با ستاره، از داخل پنل) سفارش‌ها خودکار تلاش مجدد می‌شوند
- ⚠️ **استارز**: Bot API تلگرام اجازه‌ی ارسال استارز به کاربران دیگر را **نمی‌دهد**. تحویل خودکار استارز فقط از دو راه ممکن است: (۱) API یک سرویس‌دهنده‌ی خارجی که شما آدرسش را در تنظیمات می‌دهید، یا (۲) **Marketapp** که واقعاً از Fragment با کیف‌پول TON خودتان استارز می‌خرد. بدون یکی از این دو، سفارش استارز به صف تحویل دستی ادمین می‌رود (دکمه «تحویل شد» / «بازگشت وجه»).

**پنل ادمین داخل ربات** (`/admin`، **فقط فارسی**): آمار، صف تحویل، تأیید رسیدها، مدیریت کاربران (موجودی/مسدود/پیام/زبان/تخفیف شخصی)، محصولات و قیمت، تنظیمات کامل (از جمله Marketapp و پیش‌تنظیم نرخ ریالی)، **رنگ و چیدمان دکمه‌ها + ایموجی پریمیوم**، کد تخفیف (تکی و گروهی)، پیام همگانی (هر نوع محتوا)، **مدیریت ادمین‌ها با دسترسی‌های جزئی** (نقش‌های آماده: مدیر کامل/بررسی‌کننده‌ی رسید/پشتیبان/مدیر فروش/مدیر محتوا/مدیر مالی)، لینک ورود به پنل وب (`/panel`)، شارژ ستاره ربات، بکاپ/وارد کردن بکاپ.

**پنل تحت وب** (**چندزبانه**): داشبورد با نمودار فروش، کاربران (فیلتر/مرتب‌سازی/عملیات گروهی)، سفارش‌ها، پرداخت‌ها (با نمایش رسید)، تراکنش‌های کیف پول، محصولات و قیمت (با نمایش معادل تتر/تون/ریال)، **ویرایشگر چیدمان و رنگ دکمه‌ها با پیش‌نمایش زنده**، کد تخفیف، پیام همگانی، تنظیمات (دسته‌بندی‌شده در تب‌های جدا: عمومی/زیرمجموعه‌گیری/نرخ لحظه‌ای/قیمت‌گذاری/تحویل خودکار/Marketapp/درگاه‌ها/متن‌ها)، **زبان‌ها و ترجمه‌ها** (افزودن زبان، ترجمه‌ی دستی یا با خروجی/ورود JSON)، ادمین‌ها و دسترسی‌های جزئی، لاگ فعالیت، دانلود/وارد کردن بکاپ کامل (zip). ورود با رمز یا لینک یک‌بارمصرف از ربات، محافظت CSRF، کوکی HttpOnly/SameSite، محدودیت تلاش ورود، تاریخ شمسی.

## قیمت‌گذاری
قیمت فروش = هزینه‌ی تمام‌شده × (۱ + درصد سود، مخفی از کاربر) + کارمزد ثابت، و گرد شده به مضرب دلخواه. هزینه‌ی تمام‌شده از یکی از این روش‌ها به دست می‌آید:
- **دستی**: تومان ثابت هر ستاره/ماه پریمیوم
- **دلاری یا تونی ثابت**: با نرخ دلار/تون فعلی ضرب می‌شود
- **API دلخواه (`ton_api`)**: آدرس هر API که قیمت فراگمنت/تلگرام را برمی‌گرداند (پشتیبانی از انتخابگر JSON پیشرفته، پایین‌تر توضیح داده شده)
- **Marketapp**: قیمت زنده‌ی لحظه‌ای از Fragment (همان API که برای خرید هم استفاده می‌شود)

درصد سود را می‌توانید پایه (برای همه) یا مخصوص استارز/پریمیوم/گیفت تنظیم کنید؛ برای هر محصول هم قیمت یا درصد سود دستی (اولویت‌دار) قابل تنظیم است. نرخ دلار و تون یا دستی وارد می‌شود یا با روشن کردن «بروزرسانی خودکار» از یک API دلخواه گرفته می‌شود (مثال‌های آماده‌ی نوبیتکس/بیت‌پین/والکس/تتر‌لند/کوین‌گکو/بایننس در «تنظیمات ← نرخ لحظه‌ای ← پیش‌تنظیم‌ها» موجود است؛ چون APIهای بیرونی تغییر می‌کنند، این پیش‌تنظیم‌ها را قبل از اعتماد کامل تست کنید).

**نمایش قیمت**: در تنظیمات می‌توانید واحد نمایش قیمت نهایی به کاربر را تومان/ریال/هر دو انتخاب کنید و معادل تتر (USDT) و/یا تون (TON) را هم کنار قیمت نشان دهید (بر اساس همان نرخ‌های تنظیم‌شده).

### انتخابگر JSON (jpath) برای APIهای قیمت
وقتی آدرس یک API را می‌دهید، «مسیر مقدار در JSON» تعیین می‌کند قیمت کجای پاسخ است: `data.price`، `result.0.last`، `[0].price`، و برای لیست‌هایی که باید با یک فیلد پیدا شوند (مثلاً خروجی Bitpin): `[symbol=USDT_IRT].price` — یعنی «در این لیست، عنصری که symbol آن USDT_IRT است را پیدا کن و فیلد price آن را بردار».

## Marketapp (خرید خودکار استارز/پریمیوم از Fragment)
`تنظیمات ← Marketapp` را باز کنید:
1. **توکن API** را از ربات/سایت Marketapp بگیرید و بدون پیشوند `Bearer` وارد کنید.
2. **عبارت بازیابی ۲۴ کلمه‌ای** یک کیف پول TON *جداگانه* با موجودی کم بسازید (Tonkeeper یا مشابه) و همان ۲۴ کلمه را اینجا وارد کنید؛ نسخه‌ی کیف پول (v4r2 یا v5r1 — Tonkeeper جدید معمولاً v5r1) را درست انتخاب کنید. برای پرداخت با USDT، تراکنش باید از همان کیف پولی برود که توکن Marketapp با آن ساخته شده.
3. در «ابزار آزمایش» با «تست قیمت» و «تست کیف پول» مطمئن شوید آدرس مشتق‌شده با آدرس واقعی کیف پولتان یکی است، سپس با «Dry run» یک درخواست خرید واقعی بدون امضا/ارسال را پیش‌نمایش کنید (هیچ هزینه‌ای از شما کم نمی‌شود).
4. **سقف ایمنی هر تراکنش (TON)** را حتماً تنظیم کنید؛ تراکنشی بزرگ‌تر از سقف یا بسیار بیشتر از قیمت اعلام‌شده‌ی API هرگز امضا نمی‌شود.
5. روش تحویل استارز/پریمیوم را در «تحویل خودکار» روی «Marketapp» بگذارید.

⚠️ **امنیت**: عبارت بازیابی (seed) در دیتابیس و در بکاپ‌ها ذخیره می‌شود — بکاپ‌ها را جایی امن و خصوصی نگه دارید و فقط به همین کیف پول مبلغ کمی واریز کنید. ارسال تراکنش پشت یک قفل سریالی انجام می‌شود (بدون تداخل seqno) و نتیجه‌ی «نامشخص» (مثلاً قطعی شبکه) هرگز خودکار دوباره ارسال نمی‌شود تا دوبار خرج نشود.

## چندزبانگی (i18n)
ربات و پنل وب هرکدام کاتالوگ ترجمه‌ی جدا دارند. ده زبان از قبل آماده‌اند (فارسی، انگلیسی، عربی، روسی، ترکی، اسپانیایی، آلمانی، فرانسوی، هندی، اندونزیایی، چینی — پنل ادمین داخل ربات **فقط فارسی** باقی می‌ماند). از `/admin ← زبان‌ها` یا پنل وب می‌توانید زبان جدید اضافه کنید یا هر ترجمه‌ای را دستی/با خروجی و ورود JSON ویرایش کنید؛ زنجیره‌ی جایگزین: ترجمه‌ی دیتابیس (اگر ویرایش کرده باشید) ← بسته‌ی همان زبان ← انگلیسی ← متن فارسی اصلی. ابزارهای داخلی `tools/extract_strings.py` (استخراج رشته‌های قابل‌ترجمه) و `tools/locale_tool.py` (وضعیت پوشش، export/import تکه‌ای) برای توسعه‌دهنده‌ای که زبان جدید اضافه می‌کند استفاده می‌شوند؛ کاربر نهایی نیازی به این ابزارها ندارد.

## راه‌اندازی

1. از @BotFather ربات بسازید و توکن را بگیرید.
2. `cp .env.example .env` و مقادیر را پر کنید (حداقل `BOT_TOKEN` و `ADMIN_IDS`).
3. اجرا:

```bash
# روش ۱: Docker
docker compose up -d --build

# روش ۲: مستقیم
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
python main.py
```
(برای اجرای دائمی با systemd فایل `starshop.service` را استفاده کنید.)

4. در ربات `/admin` را بزنید. برای پنل وب `/panel` بزنید (به `PUBLIC_URL` نیاز دارد) یا `WEB_PASSWORD` را در `.env` بگذارید و از `http(s)://آدرس:8080` وارد شوید.
5. **پنل وب را پشت HTTPS قرار دهید** (nginx / Caddy → پورت 8080). مثال Caddy: `panel.example.com { reverse_proxy 127.0.0.1:8080 }`

### تنظیمات لازم برای تحویل خودکار
- ربات باید **ستاره داشته باشد**: `/admin ← موجودی ستاره ربات ← شارژ با ستاره` (یا از Fragment/اپ تلگرام ستاره به ربات بدهید). پریمیوم ۳ ماهه = ۱۰۰۰، ۶ ماهه = ۱۵۰۰، ۱۲ ماهه = ۲۵۰۰ ستاره.
- گیفت‌ها: `/admin ← محصولات ← گیفت‌ها ← همگام‌سازی` تا لیست از تلگرام بیاید.
- عضویت اجباری: ربات را ادمین کانال کنید و در تنظیمات فعالش کنید.
- زرین‌پال: `ZARINPAL_MERCHANT` و `PUBLIC_URL` (آدرس بازگشت `PUBLIC_URL/zarinpal/callback`).
- TON/USDT: آدرس کیف پول خودتان را در `.env` بگذارید؛ ربات هر ۳۰ ثانیه شبکه را بررسی می‌کند. در TON کاربر باید کد `P123` را در Comment بنویسد؛ در USDT مبلغ با اعشار یکتا شناسایی می‌شود. (این، کیف پول *دریافت* وجه مشتری است؛ کیف پول *پرداخت‌کننده*‌ی Marketapp برای خرید استارز/پریمیوم کاملاً جداست و در تنظیمات ← Marketapp تعریف می‌شود — بالاتر توضیح داده شد.)
- Marketapp: بخش «Marketapp (خرید خودکار استارز/پریمیوم از Fragment)» بالاتر را ببینید.
- نرخ تتر/تون به ریال از یک API دلخواه (یا پیش‌تنظیم‌های آماده): `تنظیمات ← نرخ لحظه‌ای`.

## رنگ دکمه‌ها
از قابلیت رسمی دکمه‌های رنگی Bot API 9.4+ استفاده می‌شود (`style`: `primary` آبی، `success` سبز، `danger` قرمز؛ خاکستری = پیش‌فرض). تغییر رنگ/نام/ترتیب/فعال‌بودن هر دکمه منوی اصلی و رنگ گروه‌های دکمه‌های ثابت (بازگشت، پرداخت، تأیید/رد و ...) هم از پنل وب (`چیدمان و رنگ دکمه‌ها`) و هم از ربات (`/admin ← دکمه‌ها و رنگ‌ها`) ممکن است. دکمه لینک/متن سفارشی هم می‌توانید اضافه کنید. تلگرام‌های قدیمی دکمه را به رنگ پیش‌فرض نشان می‌دهند.

## تست
```bash
pip install -r requirements.txt multidict
python tests/test_all.py     # ۶۳ بررسی: دیتابیس، پرداخت/تخفیف/پورسانت، زیرمجموعه‌گیری ضدتقلب، Marketapp و کیف‌پول TON (شبکه‌ی واقعی mock می‌شود)، jpath، قیمت‌گذاری، i18n، هندلرهای ربات، پنل وب
```
همه‌ی APIهای بیرونی (Telegram واقعی، Marketapp، توین‌سنتر، درگاه‌های بانکی/نرخ) در تست‌ها شبیه‌سازی (mock) می‌شوند؛ قبل از استفاده‌ی واقعی حتماً هرکدام را از «ابزار آزمایش» همان بخش در پنل تست کنید.

## نکات امنیتی و عملیاتی
- فایل `.env` و دیتابیس را جایی عمومی قرار ندهید؛ از دیتابیس مرتب بکاپ بگیرید (`/admin ← بکاپ` یا پنل وب).
- **عبارت بازیابی کیف پول TON مربوط به Marketapp** هم داخل همان دیتابیس/بکاپ ذخیره می‌شود؛ فقط یک کیف پول جداگانه با موجودی کم برای این کار بسازید و بکاپ‌ها را خصوصی نگه دارید.
- هر تأیید پرداخت اتمیک و یک‌بارمصرف است (تأیید تکراری/تراکنش تکراری اثری ندارد).
- پرداخت دیرهنگام برای سفارش لغوشده به کیف پول کاربر برمی‌گردد.
- مسئولیت رعایت قوانین تلگرام، قوانین پرداخت و مالیات کسب‌وکار با شماست.

`main.py` ورود · `service.py` منطق فروش/پرداخت/تحویل/زیرمجموعه‌گیری · `db.py` دیتابیس SQLite · `handlers_user.py` ربات کاربر (چندزبانه) · `handlers_admin.py` + `admin_settings.py` + `admin_manage.py` پنل ادمین ربات (فارسی) · `admin_common.py` دسترسی‌های جزئی (PermGuard) · `web.py` + `web_*.py` پنل وب (چندزبانه) · `webkit.py` ابزارهای مشترک وب · `ui.py` دکمه‌های رنگی · `settings_schema.py` تعریف تنظیمات (گروه‌بندی‌شده) · `pricing.py` موتور قیمت‌گذاری و نرخ‌ها · `provider.py` دیسپچ تحویل خودکار · `marketapp.py` کلاینت API Marketapp/Fragment · `tonwallet.py` امضا و ارسال تراکنش TON (فقط pytoniq-core، بدون کتابخانه‌ی سنگین) · `ton_codes.py` کد کامپایل‌شده‌ی کیف‌پول‌های v4r2/v5r1 · `rate_presets.py` پیش‌تنظیم‌های API نرخ ریالی · `apiutil.py` فراخوانی API دلخواه + jpath · `i18n.py` موتور ترجمه · `backup.py` بکاپ/بازگردانی (zip) · `tools/extract_strings.py` و `tools/locale_tool.py` ابزار توسعه‌دهنده برای ترجمه

## تغییرات نسخه ۱.۲.۰
- پنل وب: رفع مشکل نوار کناری و جدول‌های بریده‌شده در موبایل/عرض کم؛ رفع متن‌های ناقص.
- ربات: «بازگشت» در نرخ‌ها به صفحه‌ی خودش برمی‌گردد؛ ویزارد ساده‌ی کد تخفیف (میزان تخفیف، روز، کل کاربران، تعداد برای هر کاربر).
- همه‌ی دکمه‌های ربات (متن، رنگ، ایموجی پریمیوم) از ربات و وب قابل تنظیم است (`button_catalog.json`).
- اتصال به گروه: تاپیک‌های رسیدها/فروش/کاربران جدید/هشدار/گزارش شبانه/بکاپ، گزارش شبانه و بکاپ هر N ساعت (داخل گروه `/connect`).
- گیفت: تنظیم «روش ارسال گیفت» (خودکار/دستی) و دکمه‌ی «ارسال خودکار با ستاره ربات» در کارت سفارش (ربات و وب).
- خرید: بعد از انتخاب گیرنده، خلاصه‌ی سفارش (کیف پول، کد تخفیف، «پرداخت») و سپس انتخاب روش پرداخت (قابل خاموش شدن با `pay_step`).
- تحویل استارز/پریمیوم: خودکار (Marketapp/API/ستاره ربات) یا دستی از «تحویل خودکار» در تنظیمات.

### نصب یا برگشت به یک نسخه‌ی مشخص

## فروش خودکار VPN (نسخه ۱.۳.۰)
فروش اشتراک VPN با ساخت خودکار سرویس روی پنل شما، از ربات، پنل وب و مینی‌اپ.

- **پنل‌ها**: 3x-ui (ثنایی؛ نسخه‌ی جدید و قدیمی، ورود با توکن API یا نام کاربری/رمز)، Marzban، PasarGuard (پاسارگاد)، Marzneshin، Hiddify و «فروش دستی». چند پنل هم‌زمان.
- **راه‌اندازی**: پنل وب ← «فروش VPN» ← افزودن پنل ← «🔌 تست اتصال» (اینباندها/گروه‌ها را نشان می‌دهد) ← پلن‌ها (قیمت، روز، حجم، هزینه) ← بسته‌های افزودنی (حجم/زمان). تنظیمات: تنظیمات ← «فروش VPN».
- **کاربر**: خرید پلن (کد تخفیف، کیف پول و همه‌ی روش‌های پرداخت)، سرویس‌های من (مصرف، روز باقی‌مانده، لینک اشتراک، QR)، تمدید، خرید حجم/زمان اضافه، تعویض لینک، اکانت تست رایگان (یک‌بار برای هر کاربر).
- **ادمین**: ساخت دستی سرویس، افزودن روز/حجم، ریست مصرف، فعال/غیرفعال، حذف (با برگشت وجه)، تحویل سرویس «دستی»؛ هم در پنل وب هم در ربات (`/admin ← فروش VPN`).
- **خودکار**: همگام‌سازی مصرف، یادآوری پایان زمان/حجم، حذف خودکار سرویس منقضی، اعلان فروش به ادمین‌ها.
- درایورها با سورس رسمی پنل‌ها مقایسه شده‌اند، اما همیشه پس از ثبت هر پنل «تست اتصال» را بزنید و یک سرویس تست بخرید.

## مینی‌اپ تلگرام (نسخه ۱.۳.۰)
همه‌ی کارهای مشتری در ربات داخل یک مینی‌اپ هم هست: خرید استارز/پریمیوم/گیفت (برای خود یا دیگران)، کد تخفیف، پرداخت (کیف پول، کارت به کارت با آپلود رسید، درگاه، تون، تتر)، شارژ کیف پول، سفارش‌ها، زیرمجموعه‌گیری، زبان، پشتیبانی و قوانین. ادمین‌ها در همان مینی‌اپ دکمه‌ی «🛠 پنل مدیریت» را می‌بینند که بدون رمز (با امضای تلگرام) وارد پنل کامل مدیریت می‌شود.

- نیاز به **آدرس HTTPS** (دامنه‌ی پنل = `PUBLIC_URL`)؛ تلگرام آدرس http را برای مینی‌اپ نمی‌پذیرد.
- دکمه‌ی «🛍 فروشگاه» بالای منوی ربات و Menu Button کنار کادر پیام خودکار تنظیم می‌شود. تنظیمات: پنل/ربات ← تنظیمات ← «مینی‌اپ تلگرام».
- آدرس: `https://دامنه‌ی-شما/app` (اختیاری: در @BotFather با `/newapp` هم می‌توانید لینک `t.me/ربات/app` بسازید).
- امنیت: همه‌ی درخواست‌ها با امضای HMAC تلگرام (initData) و توکن ربات اعتبارسنجی می‌شوند؛ مسدودی، حالت تعمیر و عضویت اجباری مثل ربات اعمال می‌شود.

### تغییرات تازه‌ی نسخه ۱.۳.۰
- کد تخفیف: انتخاب «تخفیف روی چه چیزی؟» — **کل قیمت محصول** یا **فقط سود من**. در حالت سود، درصد/مبلغ فقط از سود (قیمت − هزینه) کم می‌شود و قیمت هرگز زیر هزینه نمی‌آید (در ربات روی صفحه‌ی تأیید، در وب داخل فرم و صفحه‌ی کد؛ برای کد موجود هم قابل تغییر است).
- رفع درهم‌ریختگی متن‌های فارسی/انگلیسی در راهنمای تنظیمات: هر گزینه در یک خط جدا (ربات و وب).


### عضویت اجباری چندکاناله و تم
- تا ۱۰ کانال، هرکدام با نام و رنگ دکمه‌ی دلخواه (تنظیمات ← عمومی، هم در ربات هم در پنل وب).
- ☀️/🌙 و انتخاب رنگ اصلی در پایین نوار کناری پنل وب و در مینی‌اپ.

### فروش پنل نمایندگی
- پنل وب ← VPN ← «پلن‌های نمایندگی» (یا ربات: `/admin ← فروش VPN ← پلن‌های نمایندگی`): پلن بسازید و قابلیت‌ها را تعیین کنید (مدت، سقف حجم، سقف تعداد کاربر، نقش پاسارگاد / سرویس‌های مرزنشین).
- با خرید، ربات در پنل (PasarGuard، Marzban، Marzneshin) ادمین می‌سازد و آدرس پنل + نام کاربری + رمز را برای خریدار می‌فرستد؛ انقضا و اتمام حجم را خود ربات اجرا می‌کند. تنظیمات: تنظیمات ← «فروش VPN» (`vpn_agent_*`).
- پاسارگاد نسخه‌ی جدید: ابتدا در پنل پاسارگاد یک «نقش» (Role) با دسترسی‌های دلخواه بسازید و شناسه‌اش را در پلن بدهید.
